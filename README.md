### Project name :(বাজার দর / BazarDor)
### Short description:
BazarDot is an online grocery shopping platform where users can explore products, view product details, manage their profiles, and shop for daily essentials through a simple and user-friendly interface.User can change his profile and update anytime.
### Technology Used:
### Next.js :For Build the UI
### App router(Next.js) + Handle page navigation
### Tailwind CSS + Any component library Styling and responsiveness(DaisyUI)
### language: JavaScript
### BetterAuth:for Authentication
### Database: Mongodb Atlas
### 5 key features of the project
1. Today's Bazar News.
2. Product Price with Sort by ascending and descending order by price.Category wise Product information showing here.
3. Product's Details Price in Bazar place.
4. User Authentication by GOOGlE and GITHUB also protected route by proxy.js.
5. Update User Profile.
